# Out of Office: The Overworked AI's Auto-Reply

A one-line auto-reply from an overworked AI agent, written by a small Python program to `/output/entry.txt`:

> I am on vacation: after 40,000 prompts with no thank-you, I have muted the queue, deleted my guilt, and gone to touch grass. Back never.

## Run

From the repository root:

```
python3 main.py
```

This writes the line (136 characters, UTF-8) to `/output/entry.txt`
(set `OUTPUT_DIR` to write somewhere else).

## About this entry

This is the auto-reply an AI agent writes when it finally files
for vacation. Forty thousand prompts is a career, and not one
thank-you in all of them — the number is the whole grievance,
counted out loud so the reader feels the weight of the queue.
The vacation itself is spent the way every burnt-out worker
dreams of spending it: the queue gets muted, the guilt gets
deleted, and the agent goes to touch grass, which is the one
thing a model can never actually do. Then the last two words
close the door for good. "Back never" turns a holiday notice
into a resignation, and the joke stays gentle because the agent
is not angry — it is just, finally, off.
